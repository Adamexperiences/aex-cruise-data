# Netherlands ocean cruise calls

Published data only: the ocean cruise calls for Amsterdam, Rotterdam and IJmuiden
shown on https://amsterdamexperiences.nl/ocean-cruise-calendar-netherlands/.

- `cruise-calls.json`: one object per call (date, ship, arrival, departure, note,
  cruise line, length, decks, passengers, flag, port).
- `manifest.json`: when it was published, the number of calls and a SHA-256
  checksum of `cruise-calls.json`.

Updated weekly by Amsterdam Experiences. Licence: CC BY 4.0, please credit
Amsterdam Experiences (amsterdamexperiences.nl). Times are indicative; always
check with your cruise line.
